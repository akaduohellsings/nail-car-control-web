# 拾取重构第一步：静止定位与地面标定（2026-10-07）

本步骤只测量、拍照、计算、保存。未接入新拾取动作或自动行驶。现有前后10cm动作测试仍由原导航勾选开关控制；做标定前应停止导航任务。

## 加载入口

先结束旧网页导航整套服务，确认退出；按既有指南复位到建图起点及原朝向，完整启动网页导航。待部署标记会安装新版后端，启动过程不发导航目标。刷新网页，进入顶部“静止定位”，或访问 http://localhost:8000/pickup-localization.html 。沿用共用连接设置，不写死USB或热点地址。电脑网页服务器本身不需要新增代理接口，旧静态服务器也可直接提供新页面文件。

在导航页停止任务，等小车停稳，再进入静止定位页。点击“获取静止快照”。首次重启后相机信息和检测帧尚未到齐时可以重试；无钉子也能获取空检测的原始图像来标定。旧在线服务不支持新接口会提示完整重启。

本页不会自动播放实时视频；页面打开后没有照片时，需手动点击“获取静止快照”。按钮遇到停车反馈暂未确认、相机信息或同帧检测尚未到齐时，在8秒总预算内持续进行只读取图请求，间隔250毫秒；不再提前限于3次。后台每次仍核对停车和无控制权；持续未停稳会明确拒绝，不发送停止或其他控制命令。2026-10-07已通过热点任务服务取得640×480原始照片，并在网页实际显示。此项网页修正只需刷新页面，不必重启小车服务。

## 采集实测数据

1. 固定相机、车头磁铁及车身，保持地面平整。确定车体base_link原点在地面的投影，做一个零点标记。不要直接把车头或相机当作原点。X向前，Y向左，右侧Y为负数。相机、磁铁、所有地面点都使用同一原点。
2. 在可见地面放置至少6个小标记，覆盖前后、左右不同位置。用尺子测每个点的前方X、左侧Y，单位cm。无需沿用任何旧参考距离或旧标定文件。
3. 获取停稳快照，点击标记中心，填写X/Y，再点“加入标定点”。可以在同一冻结画面逐个选点；也可移动标记后重新拍照，车身和相机保持不动。
4. 再选至少2个不同的地面点，放在标定点围成的区域内部。实测坐标后点击“加入独立核验点”；它们不参与拟合，也不能重复前面的点。
5. 填磁铁中心的X/Y和实测有效吸附宽度，再填写安装记录，建议包含相机位置/俯角、磁铁位置/离地高度。有效宽度应现场测吸附效果，不直接使用磁铁外壳宽度。
6. 点击“计算、核验并保存”。至少6拟合+2独立核验，核验RMS≤2cm、单点最大≤3cm及拟合RMS≤2cm才通过；该标准是本步骤的初始软件核验门槛，不代表钉子精确定位已实车验收。点位退化、重复、非法数值或核验超差会拒绝保存。
7. 勾选“相机、磁铁安装及地面条件与本次标定一致”，重新拍摄地面钉子，在下拉框选择识别目标。页面显示前方距离、左右偏移、相对磁铁的横向偏差和预计直行扫过带。也可手动点击未参与标定的地面点，与尺子复核。识别使用框中心的地面近似，钉子长度和检测框误差尚未单独建模。
8. 导出标定JSON备份。标定保存在当前浏览器；导入时重新计算、核验，不信任导入文件里预先计算的矩阵。刷新或重新拍照后必须重新确认安装条件。相机内参、画幅或通道改变后拒绝估算；相机/磁铁安装变化和地面变化需要重新标定或核验。

快照为冻结画面，不是实时位置。移动小车/目标后重新获取。标定区域外拒绝距离外推；绿色区域仅为磁铁几何覆盖估计，不代表无障碍可达或磁吸成功。所有界面始终区分位置估计和 collection_confirmed=false。

## 实现边界

新增独立pickup_observation.py，订阅已有彩色Image/CameraInfo和detections。以图像源时间戳和光学frame严格配对，最多保存16图像和16检测帧，0.5秒内的新鲜配对才可取；空检测帧有效。CameraInfo要求原始plumb_bob、5个畸变系数、未裁剪/缩放，变化时清缓存；不满足时明确拒绝，不使用旧内参或预设距离。新GET /api/v1/pickup/observation沿用客户端/Origin准入，取图前后都核对在线、停车、无导航目标/待响应、owner none；不排队命令、不心跳、不取消或恢复任务、不发任何速度。图像JPEG编码依赖python3-opencv/numpy，包声明同步补齐；缺依赖时返回清晰错误。

前端pickup-geometry.js是纯几何模块：对原图点击点作径向/切向畸变逆运算，再通过归一化最小二乘求地面单应映射，使用独立点检查厘米误差。只在拟合点凸包内部估算；拒绝跨映射奇点。磁铁位置与覆盖宽度使用实测输入。未标定、相机变更或未确认安装条件时距离显示为—。

初版开发仅进行了本地与模拟快照验证；随后已完成上述真实照片显示验证，仍未采集真实地面标定点或验收磁铁吸附。后续动作模块将使用独立新实现，不恢复已删除的旧拾取代码。
