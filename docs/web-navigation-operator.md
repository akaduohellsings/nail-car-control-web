# 从开机到网页导航

当前使用 Type-C / USB 网络连接，网页把目标交给小车已有的 Nav2 单点导航。拾取暂未启用。启动服务不发送行驶目标。

## 每次开机

1. 给小车开机，接好电脑与小车的 Type-C 线。等待小车启动约一分钟。电脑端使用 USB 网络，不需要先连接热点。
2. 将小车放到这张地图的建图起点，并保持建图时的车头方向。当前启动程序以该位置为 `(0, 0, 0°)` 初始化定位；不能在任意位置启动后直接照此操作。
3. 人在小车旁，测试区域空旷，线缆有足够的行驶与转动余量。
4. 在 `C:\Users\02\Desktop\小车` 双击 **启动网页导航.cmd**。
5. 在窗口中核对现场提示，输入 **Y** 并回车。程序自动检查时间、连接小车、启动地图、定位、底盘、雷达和导航控制服务。
6. 等窗口出现 **导航已就绪**。首次通常需要几十秒；出现失败说明时保留窗口信息，不要连续重复启动。
7. 程序会打开网页：<http://localhost:8000/navigation.html>。也可以自己在浏览器中打开。

启动窗口完成后可以按任意键关闭。导航在后台持续运行，不依赖这个窗口保持打开；电脑应保持运行，USB 保持连接。

## 连接网页

1. 点击右上角 **连接设置**。
2. 小车地址填写 `http://192.168.55.1`。
3. 展开 **服务地址（可分别设置）**，将 **导航任务服务** 填为 `http://192.168.55.1:8092`。
4. 点击 **保存设置**，然后点击 **连接任务服务**。
5. 确认页面显示 **任务状态在线**、**定位可用**、**导航服务已就绪**、**停车已确认**，并且 **开始导航 / 真实导航** 按钮可用。

`8092` 是当前可以控制小车的导航服务；`8091` 是只读状态服务。网页地址的 `localhost:8000` 属于电脑，不能替换成小车地址。

连接设置保存后会沿用。刷新网页后如未连接，点击“连接任务服务”即可。只保留一个正在控制任务的导航页面。

## 选点并行驶

新版服务提供“导航时检测钉子并暂停处理（模拟拾取）”开关，默认关闭。完整启动新版服务并连接后，可以在开始导航前勾选；该次任务会在新鲜、稳定的钉子检测后取消导航，确认停车，模拟拾取与复查各等待1秒，再恢复原目标及原速度。没有真实对准、接近、磁吸动作，也不判定收集成功。同一目标持续可见时不重复触发；停车证据失效则中止，处理中点击停止不会自动恢复。暂停后需要显式恢复；更改开关只影响下一次开始。

第一阶段程序回归与部署编译通过，实际检测触发停车、再继续的现场运动仍待验证；旧运行会话不热更新。如果开关禁用，确认完整启动新版服务、刷新网页并重新连接。普通单点导航不勾选即可沿用。

开启检测决策后，开关下方显示收到的检测帧数、钉子置信度、源帧龄及具体原因（未识别到钉子、检测尚未稳定、帧过期、等待目标消失等）。这是识别与决策反馈，不代表收集成功。遇到未停车，先看这里再调整；不要仅根据放了钉子就认定模型识别到了。低电压报错后先充电，再按完整启动流程恢复。

1. 在地图白色、已知空闲区域点击一个目标点，X/Y 会自动填写。也可以直接填写坐标，单位为米。灰色未知区、黑色障碍物及靠墙位置可能被拒绝。
2. 填写 **目标朝向**，单位为度，相对于地图坐标系；`0°` 对应建图起点的原始朝向。
3. 设置 **最大移动速度** 与 **最大转向速度**。第一轮建议保留 `0.05 米/秒`、`13 度/秒`。连接新版地图导航服务后，移动速度上限为 **`0.30 米/秒`**，转向上限为 **`45 度/秒`**（新版完整启动后生效），默认仍保持约 `13.75 度/秒`，页面会显示并校验。提高允许上限不会自动把小车调到高速；本次输出仍按你填写的速度限幅，已有速度草稿会沿用。
4. 点击 **开始导航 / 真实导航** 才会发送目标。“保存目标草稿”只保存输入，不会行驶。
5. 观察车身与网页状态。到达后会显示 **已到达** 并确认停车，可以直接选择下一个点再开始，不用重新启动服务。

第一轮建议选择起点前方约 20–40 厘米的空闲点，目标朝向先保持 `0°`。网页选点到 Nav2 的接口已接通；此前侧向目标曾出现导航未取得进展，小车没有转起来，任意目标的到达能力还需现场验证。

## 暂停、重试与结束

- **暂停任务**：取消当前执行并等待停车；**恢复任务** 会继续原目标，使用该次开始时的速度。
- **停止任务**（新版连续测试服务）：取消当前导航，确认停车后清除原目标并回到待命，可重新选点开始。**暂停任务** 则保留原目标，用“恢复任务”继续。
- 已经运行的旧服务仍显示“停止并暂停任务”：停止后点击 **重置任务**，再选点开始。下一次启动服务才会加载新版停止逻辑；网页需刷新。
- 新版连续测试服务遇到普通 `NAVIGATION_ABORTED` 且停车已确认时，可以直接重新选点并点击 **开始导航**，新任务会清除旧任务故障。它不会自行重试或行驶。旧会话如果开始按钮仍禁用，先点击 **重置任务**；新逻辑在下一次启动服务时加载。
- **停止任务** 的回执按实际取消与停车结果判断，旧导航失败不会被当成停车失败。停车未确认、传感器或保护故障仍会阻止新任务，需要排查。
- **手动搬动复位**：先点击“停止任务”，等停车确认，再运行“结束网页导航.cmd”，等底盘与导航服务关闭后才搬动。放回建图起点、恢复原朝向后，运行“启动网页导航.cmd”，确认起点并等待服务就绪；网页刷新、连接后再选点。网页“重置任务”只清理任务，不重设定位。
- 如果在导航服务仍运行时搬动，速度反馈可能触发 `MEASURED_SPEED_BOUND`，保护会关闭整套服务。此时“重置任务”不能恢复，可按下面的“重启导航服务”流程重建定位。日志峰值不一定代表电机主动运动，应结合现场观察。
- 完成测试：双击 **结束网页导航.cmd**。它会先请求停车，再关闭本次启动的底盘、雷达和导航服务。等窗口显示 **导航已结束，底盘与导航服务已关闭**，再拔线或给小车关机。

当前取消了等待你操作和整轮测试的自动到期关闭；仍保留单次行驶时间限制、速度限制、地图检查、断联停车和低电压保护。低电压或反馈中断时可能结束整套服务，需要排查后重新启动。

## 服务报错退出后的网页恢复

电脑网页现在提供 **重启导航服务**，用于小车服务已退出、状态服务不可达的情况：

1. 确认小车完全停下，检查并处理原告警原因；如果仍有旧服务运行，先使用“结束网页导航.cmd”结束。
2. 将小车放回建图起点、保持原朝向，确认人在车旁、测试区域空旷、线缆有余量。
3. 打开或刷新 `http://localhost:8000/navigation.html`，点击任务状态区的 **重启导航服务**。
4. 勾选复位确认，点击 **确认复位并启动**，等待页面显示服务就绪。摄像头、YOLO、视频、移动服务及导航会按原统一启动流程启动；成功后页面自动连接任务服务。
5. 重新选点、检查速度，再点击开始导航。重启不会发送旧目标，也不会自动行驶。

**重置任务**用于服务仍在线时清理任务；**重启导航服务**用于服务退出后的恢复。新入口仅由电脑本地网页服务器提供，重复启动和网页地址与启动配置不一致会被拒绝。更换 USB/热点地址仍需同时修改启动配置与网页连接设置。若提示“本地启动入口未加载”，重新启动电脑网页服务。

## 更换 USB / 热点地址

先结束导航。在 `config/web_navigation_operator.json` 修改 `host`，然后在网页连接设置里修改小车地址与导航任务服务地址，两边需一致。例如热点地址若为 `192.168.137.2`，则 `host` 填该 IP，网页导航服务填 `http://192.168.137.2:8092`。热点名称和密码不写入程序。

`map_yaml` 是小车上的地图文件路径；`frontend_dir` 是电脑网页文件夹路径。当前控制端口固定为 `8092`。更换电脑或小车还需要确认 SSH 登录和已部署的软件，不能只改 IP。

## 常见情况

| 页面或窗口现象 | 操作 |
|---|---|
| 状态服务不可达 | 确认小车已开机、USB 连接正常、启动窗口已报就绪，网页导航地址为 `:8092`。 |
| 地图已显示但开始按钮不可用 | 查看定位、停车确认、告警和操作页面是否被其他页面占用；先停止并重置，必要时重新连接。 |
| 导航失败 / Failed to make progress | 确认小车已停，重置任务后换近处目标。保留告警供排查。 |
| 启动提示旧服务仍在运行 | 先运行“结束网页导航”，确认关闭后再启动；不要另起一套服务。 |
| 小车重启或充电后 | 从本指南第一步重新开始，重新确认起点和朝向。 |
| 结束窗口未确认停车或关闭失败 | 保留窗口与日志，现场检查车是否静止，勿立刻重复启动。 |
| 已显示导航已结束，同时有摄像头图像压缩退出警告 | 本次服务已核验关闭，运行记录已结束；压缩子进程异常仍保留在日志中，不表示导航继续运行。其他未确认停车或进程残留仍按关闭失败处理。 |

启动日志在 `test_results/web_navigation_operator_日期时间.log`；启动记录在 `test_results/web_navigation_operator_session.json`。请保留这些文件用于继续排查。

## 统一启动摄像头、YOLO 与网页服务

“启动网页导航.cmd”现在按顺序启动摄像头，收到三帧新鲜图像后，在独立 wheeltec 环境中启动 YOLO；确认标注图像后启动视频服务（8080）和原移动控制服务（5000），再完成底盘与导航检查。等待窗口报就绪后使用网页。初始化模型会增加等待时间；摄像头或 YOLO 未就绪会报错并关闭本次已启动进程。

手动与视频页为 http://localhost:8000/index.html，连接设置中的视频地址使用当前小车地址的 8080 端口、话题 /detected_image，移动服务为 5000 端口；导航服务仍为 8092。热点与 USB 都沿用可编辑连接设置，启动过程不改写地址草稿。

尚未接通实车方向按钮与导航的控制权切换。旧移动服务的 /cmd_vel 没有接到当前受保护底盘输入，不能用于驾驶或停止正在执行的导航；导航与拾取请使用导航页的“停止任务”。检测与拾取现已接入，按下方开关显式启用。

已有导航会话会被启动入口复用，不会补启动新服务。要加载统一启动功能，先运行结束入口，确认关闭；复位到建图起点和原朝向，再完整启动。结束入口同时关闭本次启动的摄像头、YOLO、视频与移动服务。独立手动启动的旧进程不会被接管，应先自行结束，避免重复启动。

统一启动已核验相机、校正、YOLO 和 HTTP 服务。本轮静止预检因电压低于10 V中止，真实拾取仍待充电后的动作验收。

## 车头磁铁真实拾取

启动配置 `config/web_navigation_operator.json` 的 `real_pickup: true` 启用真实拾取支持，false 保留模拟处理；换网络仍修改 host，不写死热点信息。完整启动新版后刷新导航页，勾选“导航时检测钉子并执行真实拾取（车头磁铁 · 28 cm）”，再选点开始。不开启该开关时只导航。

首次采用导航 0.05 m/s、约13°/秒，在空旷区域用一颗正前方可见钉子测试。检测停车后，拾取独占底盘并沿用现有图像对准/接近，再前进28 cm清理；严格确认停车与归还控制权后恢复原导航目标。拾取最大速度固定0.04 m/s、转向0.24 rad/s，不随网页导航速度提高。

网页显示真实拾取阶段和完成动作次数。固定磁铁无需电磁开关；“动作完成”仍需现场确认是否吸附，未自动声明收集成功，也未增加后退复查。运行时保持网页前台，点击“停止任务”会取消正在执行的导航和拾取。先关闭整套服务再人工复位。当前电压约9.88–9.90 V，充电后再试。

## 流程测试的到达条件与自动停止

“重启导航服务”状态会核对当前机器人接口：通过命令行启动的新服务就绪后，旧的网页启动失败记录不会继续作为当前状态显示；已就绪服务后来不可达时也会显示离线。正在启动期间仍等待完整启动检查。该状态查询只读，不会重定位或发送目标。

地图单点导航到达容差已放宽到位置 10 厘米、朝向 15°，用于先跑通流程；当前位置在线参数已更新，下次完整启动也保留。任务仍由 Nav2 返回成功，并确认停车后开放下一次，不把肉眼看似到达直接记为成功。

测试时保持导航网页在前台并拥有焦点。当前导航页切换窗口、进入后台会主动请求停止；控制心跳失联也会停车。页面会记录“导航页面失去焦点/进入后台，自动请求停止任务”，方便与用户手动停止和真正超时区别。单点300秒限制与保护仍保留。

## 转向速度与单次任务时长

地图导航最大转向速度已提高到 45°/秒（π/4 rad/s），单次导航与保护层执行时间上限均为 300 秒。默认最大移动仍为 0.05 米/秒，默认转向仍约 13.75°/秒；请在网页主动设置需要的速度。暂停/恢复仍沿用原任务速度。

进展检查仍为60秒无位置位移时失败，独立于300秒任务上限；断联、低电压、碰撞与反馈异常仍可能提前停车。新版接口、独立保护与导航参数必须一起通过结束/完整启动加载，当前运行旧会话不会热更新。先结束服务并确认关闭，再人工复位到建图起点与原朝向，启动后刷新网页。
# 多点导航（2026-10-06）

新版支持“导航方式 → 多点导航”。在地图选点、填写朝向后点击“加入当前点”，按需要上移、下移或移除；最多20点。设置速度后点“开始导航”，服务端依次执行，每点停车确认后自动去下一点；任务状态显示进度。草稿自动保存在浏览器，刷新不会自动启动。

暂停保留队列，停车后可恢复；停止结束整个队列，重置清除服务端队列。故障中断，不自动跳点。每点执行时限300秒，地图编号连线仅表示点序。拾取仍断开，页面失焦自动停止机制保留。

更新须先运行“结束网页导航.cmd”，停车并关闭整套服务后复位到建图起点及原朝向，再运行“启动网页导航.cmd”（先自动部署），刷新页面并连接当前小车8092任务服务。本轮通过本地模拟与接口测试，实车多点仍待现场验证。
